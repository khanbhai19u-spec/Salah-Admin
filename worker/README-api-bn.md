# Salah Time API — Worker সেটআপ

এই Worker দিয়ে অন্য ডেভেলপাররা আপনার দেওয়া API key ব্যবহার করে Salah Time-এর ডেটা নিতে পারবে: নামাজের সময়, সেহরি-ইফতার, হিজরি তারিখ, কিবলা, আর অ্যাপের দোয়া, ৯৯ নাম, হাদিস ও লেখা।
কে কোন ডেটা পাবে, দিনে কতবার পাবে, সব এডমিন প্যানেল থেকে আপনি ঠিক করবেন।
আগের দুইটা Worker (নোটিফিকেশন আর ইমপোর্ট) যেমন আছে তেমনই থাকবে। এটা আলাদা।

## ১. ডেটাবেস (D1) বানান
1. dash.cloudflare.com → Storage & Databases → D1 → Create database, নাম দিন `salah-api`।
2. টেবিল বানাতে হবে না, Worker প্রথমবার চালু হলে নিজেই বানিয়ে নেবে।

## ২. Worker বানান
1. Workers & Pages → Create → Worker, নাম দিন `salah-api`।
2. Edit code-এ `api-worker.js` ফাইলের পুরো লেখা বসিয়ে Deploy করুন।
3. Settings → Bindings → Add → D1 database: Variable name `DB`, ডেটাবেস `salah-api`।
4. Settings → Variables and Secrets-এ দুইটা সাধারণ variable দিন:
   - `PROJECT_ID` = `salah-time-fe99b`
   - `ADMIN_UID` = এডমিনের uid (এডমিন প্যানেলের সেটিংসে আছে)
5. কোনো Secret লাগবে না। key গুলো ডেটাবেসে hash করে রাখা হয়, আসল key কেউ দেখতে পায় না।

## ৩. এডমিন প্যানেলে
1. সেটিংস → "API Worker URL"-এ Worker-এর লিংক দিন (যেমন `https://salah-api.<আপনার-নাম>.workers.dev`)।
2. "সেভ করুন" চাপলে লিংকটা অ্যাপের config-এও যায়, ফলে ওয়েবসাইটের API পেজের ফর্ম নিজে থেকেই কাজ শুরু করবে।

## কাজ যেভাবে চলে
1. কেউ ওয়েবসাইটের API পেজে ফর্ম পূরণ করে key চায়।
2. এডমিন প্যানেল → API Keys → "অনুরোধ"-এ সেটা আসে।
3. আপনি কোন কোন ডেটা দেবেন (scope) আর দিনে কতবার (limit) বেছে "অনুমোদন" দেন।
4. নতুন key একবারই দেখায়। কপি করে ইমেইলে পাঠিয়ে দিন। পরে আর দেখা যায় না, হারালে নতুন key দিতে হবে।
5. যেকোনো সময় key বন্ধ, scope বদল, limit বদল বা মুছে ফেলা যায়।

## ফ্রি সীমা
Cloudflare-এর ফ্রি প্ল্যানে দিনে ১ লাখ request আর D1-এ দিনে ১ লাখ লেখা পর্যন্ত চলে। প্রতিটা API request-এ একবার লেখা হয় (কতবার ব্যবহার হলো গোনার জন্য)।
